# Active Review — demo

Δημόσιο demo του plugin κριτικών Active Review σε WordPress Playground.

- Σελίδα: https://thwmaslazaroy-dev.github.io/active-review-demo/
- Περιέχει μόνο το παραδοτέο zip, το `blueprint.json` και τη σελίδα εισόδου.
- Ο πηγαίος κώδικας και τα tests είναι σε ξεχωριστό private repo.
- Ενημέρωση: `tools/build_zip.py` και `demo/build_blueprint.py --zip-url …` στο private repo, μετά αντιγραφή εδώ.
